## 📌 ELEMENTOS COMUNES

### Colores por Tipo de Movimiento
```
💚 INGRESO (Verde Cian #4ECDC4)
   Ejemplo: +$1500.00

❤️  GASTO (Rojo #FF6B6B)
   Ejemplo: -$50.00
```

### Colores de Alerta (Presupuesto)
```
🟢 Verde: Menos de 80% usado - ¡Bien!
🟡 Amarillo: 80-99% usado - Cuidado
🔴 Rojo: >100% - ¡Alerta! Superaste presupuesto
```

### Elementos Recurrentes
```
[+] Botón Flotante     → Agregar nuevo
[✏️] Botón Editar       → Modificar
[🗑️] Botón Eliminar    → Borrar (con confirmación)
[← ] Botón Retorno     → Volver atrás
[☚ ] Botón Atrás       → Ir a pantalla anterior
[⚙️] Rueda Ajustes      → Configuración
```
